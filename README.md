# Asly's Portfolio

A small Django portfolio with Home, About, and Contact pages. Shared navigation and page layout are in `templates/base.html`.

## Open in PyCharm

Open this `portfolio_site` folder as a project. Select its `.venv` Python interpreter, then run this in PyCharm's terminal:

```powershell
python -m pip install -r requirements.txt
python manage.py runserver
```

Visit `http://127.0.0.1:8000/`. The Tailwind browser CDN needs an internet connection to load the colors and layout.
